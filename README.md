# Smart Finance Assistant
## Overview
This project is a Smart Finance Assistant built by phyton and ai tools

The assistant can assist in: 
-analysing transaction CSV files 

-give budgeting advice 

-calculate saving goals 

-chat with users about finance 

#features
- finance chatbot

- CSV spending analysis

- Saving calculator

- Gradio interface


#technologies used 

-phyton 

-pandas

-gradios 

-Hands on Ai tool 

#how to run 
1. Open the notebook in google collab
2. install required packages
3. Run all notebook files
4. upload a CVS transaction files
5. start chatting with assistance

#example question 
- How much i spend on food?
- What was my biggest expences?
- how much should I save monthly to reach my goal?
